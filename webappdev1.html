Overview

Rentables is a movie collection web app that allows users to create, rate, and organize collections of their favorite (and least favorite) movies. The app was designed with a nostalgic 80s/90s Blockbuster aesthetic, featuring a retro-inspired color palette and typography.

The project was developed from scratch using React.js for the front-end, and a Node.js + Express backend to handle authentication, user sessions, and database operations. PHP and Handlebars were used for server-side rendering where required.

User Authentication

Registering & Logging In

The application includes a complete authentication system. New users can sign up by creating an account with an email and password, while existing users can log in securely. Session management was implemented to keep users logged in across the platform.

I also added the ability for users to upload a custom profile picture, giving accounts a more personalised feel. The login flow was designed to be lightweight and intuitive, ensuring minimal friction when joining the app.

Home Page

The homepage was built in React.js and styled to emulate the nostalgic look of 80’s and 90’s Blockbuster video stores. I used a blue and yellow palette and bold typography to give it a retro aesthetic, while still keeping the layout clean and responsive.

Interactive buttons and links lead users to different sections such as “Learn More,” which brings them to an about page explaining the app. A live statistics widget dynamically updates to show the number of collections created by users, adding a sense of community engagement.

about page

For the project brief, we were asked to use fictional characters on the about page. I chose Walt Jr. from Breaking Bad as a playful nod to pop culture. This page gave me the chance to experiment with creative content and styling while still using React components to keep the design modular.

Creating & Managing Collections

One of the core features of Rentables is the ability for users to create movie collections. Using forms connected to the backend, users can add titles, descriptions, and images for each movie.

Collections can then be browsed from the user’s dashboard, where I implemented a dynamic React state management system to ensure that new additions appear instantly without needing a full page refresh.

Movies can also be rated, and ratings are reflected across the user’s profile to provide a sense of progression and engagement.

Reflection

Building Rentables challenged me to think as both a frontend and backend developer. On the frontend, I strengthened my skills in React.js, particularly in managing state and creating reusable components. On the backend, I learned how to connect routes, handle authentication, and manage dynamic data efficiently using Node.js and Express.

Styling the project with a unique retro theme helped me refine my design skills, balancing creativity with usability. More importantly, this project gave me real experience in planning, structuring, and delivering a full-stack application — from concept to deployment. It was a strong step forward in my journey toward becoming a versatile developer who can handle both design and technical challenges.
